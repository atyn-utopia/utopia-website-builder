## Executive Summary

This SEO plan provides a comprehensive keyword strategy, page structure, and content requirements for Scaffolding Malaysia - a rental-focused scaffolding business targeting the Malaysian market across 200+ cities in three major languages (Malay, English, Mandarin).

**Key Strategy Points:**
- Malay is the PRIMARY language (highest user base for local construction services)

### 1.3 Keyword Cannibalization Prevention

**Rules:**
1. **Homepage** targets generic national keywords ONLY (no city name in primary keywords)
2. **Location pages** target city-specific keywords ONLY (always include city name)
3. Each location page is unique (no duplicate content across cities)
4. Product terms appear across all pages, but differentiated by location
5. Blog posts target informational keywords (how-to, guides) and link to transactional pages

**Example:**
- Homepage (ms): `sewa scaffolding malaysia` ✅
- Homepage (ms): `sewa scaffolding kuala lumpur` ❌ (belongs to location page)
- Location page (KL): `sewa scaffolding kuala lumpur` ✅
- Location page (KL): `sewa scaffolding malaysia` ❌ (only in breadcrumb/internal links)

## 5. Multilingual SEO Requirements

### 5.1 Hreflang Configuration

**Implementation:**
Every page must include hreflang tags in the `<head>` section to tell search engines about language/region variations.

**Example (Kuala Lumpur location page):**
```html
<head>
  <!-- Self-reference -->
  <link rel="alternate" hreflang="ms" href="https://scaffolding-malaysia.vercel.app/ms/scaffolding/kuala-lumpur" />
  <link rel="alternate" hreflang="en" href="https://scaffolding-malaysia.vercel.app/en/scaffolding/kuala-lumpur" />
  <link rel="alternate" hreflang="zh-Hans" href="https://scaffolding-malaysia.vercel.app/zh/scaffolding/kuala-lumpur" />

  <!-- Default fallback (Malay) -->
  <link rel="alternate" hreflang="x-default" href="https://scaffolding-malaysia.vercel.app/ms/scaffolding/kuala-lumpur" />
</head>
```

**Hreflang Codes:**
- `ms` — Malay (PRIMARY, also x-default)
- `en` — English
- `zh-Hans` — Simplified Chinese (Malaysian market uses Simplified, not Traditional)
- `x-default` — Default for unmatched locales (points to Malay)

**SEO Reasoning:**
- Prevents duplicate content issues across languages
- Ensures users see correct language in search results
- Signals to Google which version to serve to which audience

---

### 5.2 Language-Specific Keyword Differences

#### Malay vs English
- Malay: `sewa` (rent) comes BEFORE product → `sewa scaffolding`
- English: product comes BEFORE action → `scaffolding rental`
- Malay: formal business tone → `perkhidmatan`, `pembekal`
- English: conversational B2B tone → `services`, `supplier`

#### Mandarin Specifics
- Simplified Chinese for Malaysia (NOT Traditional Chinese)
- Formal business terms: `租赁` (zūlìn - rental), `出租` (chūzū - for rent)
- Product placement: keyword can come first or last → `脚手架租赁` OR `租赁脚手架`
- Use full country name: `马来西亚` (mǎláixīyà - Malaysia)

```json
}
```

**Dynamic Requirements:**
- Position 1: Always homepage
- Position 2: Current city page
- `name` field matches page H1
- `item` field is full absolute URL

**SEO Purpose:**
- Shows page hierarchy in search results
- Improves crawlability
- Enhances UX (visible breadcrumb trail in SERPs)
